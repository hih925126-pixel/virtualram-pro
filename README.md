# FocusTimer

A single-file timer app: clock, countdown timer, stopwatch, Pomodoro, and a Focus Mode
that can actually watch your Windows apps and sound an alarm when a blocked app opens.

**Live app:** https://hih925126-pixel.github.io/virtualram-pro/

Everything runs locally in your browser. No account, no tracking, no server.

## Features

- **Clock** — big local time, date, day progress, analog clock, and world clocks.
- **Timer** — presets or custom hours/minutes/seconds. Start, pause, resume, +1 min, snooze.
  The alarm loops until you dismiss it.
- **Stopwatch** — centisecond display, laps with split times.
- **Pomodoro** — configurable focus / short break / long break lengths and cycle, plus daily
  focus-session count.
- **Focus mode** — choose what's allowed, start a session, and get an alarm if something else
  opens. Two guard options:
  - **Allowed apps (Windows guard)** — the app generates a small Windows guard file.
  - **Only this tab** — no setup; an alarm fires when you leave the tab and come back.

Keyboard: `1`–`5` switch views, `Space` start/pause, `R` reset, `L` lap in the stopwatch.

## Use it

- **Online:** open the live link above. On a phone, use **Add to Home Screen** to install it
  as an app.
- **Offline:** download `index.html` and double-click it. It opens in your default browser and
  works with no internet connection.
- **Desktop:** use the browser menu to install the page as an app, or drag it to your taskbar.

Works in Chrome, Edge, Firefox, and other modern browsers.

## Using the Windows Focus guard

The web page itself can't see other desktop apps — browsers don't allow that. Focus Mode solves
it with a small local guard file:

1. Open **Focus**, pick **Allowed apps**, select the apps you need, and choose a duration.
2. Click **Start focus session**.
3. Click **Download Windows guard**. A file named `FocusGuard-<duration>.bat` downloads.
4. Close any app you don't want open *before* starting the guard. The guard only watches for
   apps opened after it starts.
5. Double-click the downloaded `.bat` file. Keep its black window open while you work.

If a new app window appears that is not on your allow list, the guard beeps and prints the app
name in red. If **Auto-close blocked apps** is enabled, it also closes that app. The guard stops
automatically at the session end time. Press `Ctrl+C` in its window to stop early.

Notes:

- Windows system essentials (Explorer, the terminal, the guard itself, etc.) are always allowed.
- The guard is generated locally on your PC. It only compares local process names; it sends
  nothing anywhere.
- Chrome may warn that `.bat` files can be dangerous. Choose **Keep** — the file is generated by
  this app on your machine and contains only the guard script.
- If Windows SmartScreen asks about the downloaded `.bat`, choose **More info → Run anyway**.
- The page keeps the focus-session countdown. The guard runs independently, so keep both the
  page and the guard window open.

The **Only this tab** mode is a lighter option for staying on the timer page. It raises the alarm
when you switch away for more than 2 seconds and come back. It does not monitor other apps.

## Good to know

- Alarm audio starts only after your first click (browser autoplay rules). Use **Settings** to
  test the tone and set the volume.
- Desktop notifications are optional. Use **Settings → Desktop notifications** and allow them in
  the browser. On HTTPS (the live link) notifications work properly.
- Timers use wall-clock time, so they stay accurate if the tab is in the background. Closing the
  browser or shutting the PC stops any running timer.
- Settings, selected apps, and Pomodoro progress are stored in this browser's local storage for
  this site. **Settings → Reset all settings** clears them.
- Mobile browsers may pause background pages when the screen is locked, so alarms are most
  reliable while the page stays open. The Focus guard is Windows-only; the rest of the app is
  cross-platform.
